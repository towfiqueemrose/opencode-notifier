OpenCode extension guide

OpenCode Notifier

Desktop toast, attention chime, and Telegram messages when an OpenCode task finishes or needs your input.

Version 1.0.1 Windows · macOS · Linux OpenCode 2.4+ github.com/towfiqueemrose/opencode-notifier

What you get

OpenCode eventToast and chimeTelegram
Task completesOpenCode Task Completed✅ message
Task is interruptedOpenCode Task Interrupted⏹ message
Task failsOpenCode Task Failed❌ message
The question tool asks you somethingOpenCode Question❓ message
A permission request needs approvalOpenCode Permission Required🔐 message

Only one of several open TUI windows claims an alert, so a single event does not send duplicate messages.

Before you start

  • OpenCode 2.4 or newer, running in a terminal TUI. Headless runs do not alert.
  • A Telegram account if you want Telegram delivery.
  • A terminal where the opencode command works.
Quick start
1 Install the plugin
2 Run /notifier
3 Run /notifier-test

Step 1 — Install the plugin

Choose one method. Do not install both; two copies would run at the same time.

Recommended

A. Install from GitHub

One command. Updates through OpenCode.

$ opencode plugin add github:towfiqueemrose/opencode-notifier

Restart OpenCode if /notifier is not available right away.

Works on Windows, macOS, and Linux. Update later with opencode plugin update.

Offline

B. Install from the zip

Use this when the sender shared opencode-notifier.zip.

Windows:

Expand-Archive opencode-notifier.zip -DestinationPath .
cd opencode-notifier
powershell -ExecutionPolicy Bypass -File .\install.ps1

macOS / Linux:

unzip opencode-notifier.zip
cd opencode-notifier
./install.sh

Restart OpenCode after the installer finishes.

Check the install Run opencode plugin list from your home directory. You should see opencode-notifier. Then restart the TUI before continuing.

Step 2 — Create your Telegram bot

Each person needs their own bot. Never share a bot token.

1

Open @BotFather in Telegram and send /newbot.

2

Choose a display name and a username ending in bot.

3

Copy the token BotFather sends you. It looks like 123456789:AA....

Step 3 — Connect the bot in OpenCode

Run this command in the OpenCode TUI:

/notifier
1

Paste the bot token when the wizard asks for it.

2

The wizard validates the token and shows the bot username.

3

Open https://t.me/<botusername> in Telegram and press Start.

4

Return to OpenCode and choose Check again. The wizard finds your chat automatically.

5

It sends a test message, then saves ~/.config/opencode/telegram.json.

Step 4 — Test it

Run the built-in test in the TUI:

/notifier-test

You should see an OpenCode Task Completed toast, hear the chime, and receive a Telegram message. The TUI also shows a small confirmation with the status of each channel.

Test the live events

  • Ask the agent to use the question tool. You should get an OpenCode Question toast and a ❓ Telegram message.
  • Trigger an approval prompt, for example by reading a real .env file. You should get OpenCode Permission Required and a 🔐 Telegram message.

Configuration

The plugin works without editing configuration. Credentials live in:

~/.config/opencode/telegram.json

Environment variables override the file, which is useful for shared machines or scripts:

OPENCODE_TELEGRAM_TOKEN=123456789:AA...
OPENCODE_TELEGRAM_CHAT_ID=123456789

Sounds

The plugin uses OpenCode's built-in sound names: done, subagent_done, question, permission, and error. To use your own WAV or MP3 files, override them in cli.json:

{
  "attention": {
    "sounds": {
      "question": "C:/Users/me/sounds/question.wav",
      "permission": "C:/Users/me/sounds/permission.wav"
    }
  }
}
Telegram is one-way Messages only notify you. Answer questions and approve permissions in the OpenCode TUI.

Troubleshooting

ProblemFix
Telegram says chat not foundOpen the bot chat and press Start, then run /notifier again.
Chat detection blocked by a webhookEnter the chat ID manually in the wizard. Get it from @userinfobot in Telegram.
No Telegram messagesCheck that telegram.json exists and has "enabled": true. Run /notifier-test.
No toastOn Windows the toast comes from PowerShell and may be attributed to Windows PowerShell. Check Focus Assist and notification settings.
No question or permission alertConfirm the request happened while a TUI with the plugin was connected. Headless runs do not send these alerts.
Plugin not loadedRun opencode plugin list, restart OpenCode, and check ~/.local/share/opencode/log/opencode.log for plugin errors.
Need detailsEnable "debug": true in the plugin options and read ~/.config/opencode/opencode-notifier-debug.log.
Keep your token private A Telegram bot token gives full control of that bot. Never commit telegram.json or paste the token into a chat, issue, or screenshot. Each person should create their own bot with @BotFather.

Disable or uninstall

Remove the GitHub install:

opencode plugin remove opencode-notifier

For the zip install, delete the folder:

~/.config/opencode/plugins/opencode-notifier

Your telegram.json is not deleted automatically. Remove it yourself if you want to erase the credentials.
